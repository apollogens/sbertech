# Дополнение к протоколу: прежний L2

После начала выполнения `experiment_protocol.json` независимый проверяющий обнаружил, что исходные два окна при официальном rank выбирали L2 z0.25, тогда как исходный minmax выбирал Tweedie z0.25. Поэтому в фиксированный расширенный набор добавлены `lgb_l2` и `lgb_l2_z0.25` с прежними 220 итерациями, PARAMS и порогом. Новые параметры не подбираются.

Это дополнение принято после просмотра части результатов новых кандидатов. Сравнение с L2 считается ретроспективным исследовательским дополнением; оно не объявляется полностью заранее зарегистрированным экспериментом. Первоначальный JSON сохраняется без изменений. Все 17 кандидатов оцениваются на одних пяти окнах; terminal остаётся только диагностическим. Основания для изменения производственной модели проверяются на первых четырёх окнах, ограничения и ухудшения публикуются. Сохранение incumbent допустимо при отсутствии убедительного выигрыша; такой вывод не означает, что он оптимален среди всех возможных моделей.
