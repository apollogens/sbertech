# Возврат к исходному состоянию

До изменения существующего кода создаются `pre_merge_snapshot.zip` и `pre_merge_manifest.json`. Git пока не имеет HEAD, поэтому вымышленного commit ID нет. Snapshot включает исходники, конфигурацию, все модели и научные NPZ. Большие уже существующие ZIP и некоторые generated CSV не дублируются, но остаются на месте и записаны в SHA-256 inventory. Исходные CSV данных не изменяются.

Безопасный rollback выполняется в **новую пустую папку**, а не поверх текущих пользовательских изменений: извлечь snapshot, проверить members по manifest, установить прежний `requirements.lock` в новую venv, скопировать неизменённые исходные данные/кэш при необходимости и запустить `MODEL_DIR=model` c `uvicorn app.main:app --workers 1`. Выбор исходного bundle nonton-v1 восстанавливается без retraining. Старые release ZIP и Docker image tags остаются доступными.

Rollback исполнен: `consolidation/verify_rollback.py` извлёк 1003 файла в `consolidation/rollback_verified_complete`, сверил каждый SHA-256 и запустил старую модель на 180-дневном входе. Получены 562496 строк, максимальное отличие от reference 3.55×10⁻¹⁵. Отдельный QA повторил сверку архива и всех извлечённых файлов. Доказательства — `rollback_verification.json` и `independent_review_evidence/rollback_hashes.json`.

Для повторного восстановления выберите новую пустую папку, проверьте SHA-256 `pre_merge_snapshot.zip` = `24ad0e89ddf31f37bb78315c94fa877244b3d90d114aba8a2e2af60ea3eb84a7`, распакуйте ZIP через `Expand-Archive -LiteralPath consolidation/pre_merge_snapshot.zip -DestinationPath <новая_папка>`. В ней создайте venv Python 3.12 и установите извлечённый `requirements.lock`. Затем из этой папки: `$env:MODEL_DIR=(Resolve-Path model).Path`; `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1`. Для быстрого возврата только к incumbent в новом приложении достаточно восстановить `config/runtime.json` с `active_bundle=../model`, `active_strategy=nonton-v1`, убрать переопределяющие переменные среды и перезапустить API. В поставленном состоянии он уже активен.
