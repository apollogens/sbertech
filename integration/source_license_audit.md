Факт публичного GitHub remote не является найденной open-source лицензией. Требуемая пользователем пара источников пока не идентифицирована однозначно; поэтому правовой clearance «обоих решений» не заявляется.

`integration/source_audit/verify_source_fixtures.py` не сохраняет upstream implementation: он читает уже inspected source, извлекает AST выбранных численных функций только в память и проверяет synthetic inputs. Чужие setup, тренировочные scripts, произвольные импорты source и pickle не исполняются. Полученный JSON содержит собственные результаты и хеши, не исходники. Для повторения нужна прежняя локальная копия; source не скачивается во время inference.

NumPy — зависимость существующего проекта. Новая исследовательская реализация использует его публичный API `rint`; это отдельный dependency contract. Сохраняются обычные dependency notices поставки; код документации не копируется. Статья Wang et al. цитируется библиографически, без копирования текста или рисунков.
